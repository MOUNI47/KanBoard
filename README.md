A simple and interactive Kanban Board web application that helps users manage tasks efficiently using Todo, Doing, and Done columns. Tasks can be created dynamically, dragged between columns, and saved using browser localStorage.

📌 Features

✅ Three columns: Todo, Doing, Done

➕ Add tasks dynamically

🖱️ Drag and drop tasks between columns

💾 Persistent data using localStorage

🎨 Clean and user-friendly UI

🌐 Fully browser-based (no backend required)

🛠️ Technologies Used

HTML – Structure of the application

CSS – Styling and layout

JavaScript – Functionality, drag & drop, and localStorage
